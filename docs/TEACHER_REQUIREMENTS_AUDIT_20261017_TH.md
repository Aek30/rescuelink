# ตรวจความครบถ้วนตามโจทย์อาจารย์ — 17 ตุลาคม 2569

## ข้อสรุป

โค้ดรองรับฟีเจอร์หลักเกือบทั้งหมด แต่ยังไม่ควรระบุว่าเสร็จสมบูรณ์หรือรับรองเกรด A: มีข้อจำกัดการเริ่มใช้งานออฟไลน์และพิกัด SOS รวมทั้งขาดหลักฐาน acceptance ของรุ่นปัจจุบันบนโทรศัพท์จริงและชุดส่งงานฉบับสุดท้าย การประเมินนี้ตรวจ source, tests และเอกสารใน workspace ไม่ใช่การทดสอบวิทยุหรือ Cloud จริงรอบใหม่

## ประเด็นที่ควรปิดก่อนส่ง

1. **เริ่มใช้งานออฟไลน์:** `lib/main.dart` เลือก Onboarding เมื่อไม่มี session และ Onboarding พาไป Login ไม่มีทางเข้า SOS โดยไม่ Login ถ้าจะอ้าง “ทุกฟีเจอร์หลักออฟไลน์” แบบไม่มีเงื่อนไข ควรมีโหมดฉุกเฉิน local หรือขอให้อาจารย์รับทราบเงื่อนไขต้องเตรียมบัญชีก่อนเกิดเหตุ
2. **พิกัดล่าสุด — แก้โค้ดแล้ว:** เพิ่ม last-known location ถาวรใน SQLite ของบัญชี พิกัดใหม่ยังตรวจอายุไม่เกิน 2 นาที แต่ fallback ยอมรับพิกัดเก่าโดยคง timestamp เดิมและแสดงคำอธิบายก่อนส่ง หากไม่มีพิกัดในฟอร์มจะตรวจ cache ก่อนเปิดกล่องยืนยัน ยกเว้นผู้ใช้กดลบพิกัดเอง ไม่มี cache/ข้อมูลเสีย/เวลาในอนาคตจะไม่สร้างพิกัดขึ้นมา ต้องทดสอบบนมือถือจริงก่อนรับรอง
3. **คำว่า “ทันที”:** การประกาศสถานะหลังเชื่อมต่อกับการค้นพบเครื่องใหม่เป็นคนละช่วง ควรบันทึกเวลาจริงทั้งสองกรณี รวมการยกเลิกและสถานะหมดอายุ
4. **หลักฐานโทรศัพท์:** มีคู่มือสามเครื่อง แต่คู่มือไม่ใช่ผลทดสอบ ต้องบันทึกรุ่น/Android/build/วันที่/ผลจริง/วิดีโอ
5. **เอกสารเก่า:** README และ REQUIREMENTS_ROADMAP มีสถานะยุคก่อนที่ขัดกับโค้ด; phase4-verification และ APP_SYSTEM_EXPLAINED_TH ยังอธิบายสื่อแบบ manual upload และข้อจำกัดเก่าบางส่วน ควรทำสถานะปัจจุบันไว้ต้นเอกสารแล้วแยกประวัติ

## ชุด acceptance ที่แนะนำให้บันทึกผลจริง

ทุกข้อยังเป็น checklist ที่เสนอ ไม่ใช่ผล PASS ของรอบตรวจนี้

1. A/B ปิด mobile data ไม่ต่อ router และไม่เปิด hotspot แต่เปิด Bluetooth/Wi-Fi radio ค้นหาและเชื่อมกันได้
2. ส่งข้อความไทยสองทิศทางและได้รับ ACK
3. เปิด/ปิด SOS แล้วอีกเครื่องเห็นสีแดง/ยกเลิกถูกต้อง พร้อมเวลาที่ใช้
4. เปิด/ปิด Rescue แล้วอีกเครื่องเห็นสีน้ำเงิน/ยกเลิกถูกต้อง
5. แตะสถานะเข้าห้องสนทนาของคนที่ถูกต้อง
6. ส่ง SOS พร้อมพิกัด ตรวจตัวเลขและเวลา; ทดสอบปฏิเสธสิทธิ์และ GPS timeout
7. ส่งรูปแบบออฟไลน์ เปิดดูบนเครื่องรับและหลัง restart
8. ส่งวิดีโอแบบออฟไลน์ เล่นบนเครื่องรับและหลัง restart
9. ตัดการเชื่อมต่อกลางส่งไฟล์ ต้องไม่ขึ้นถึงเครื่องรับ; เชื่อมใหม่แล้วได้ไฟล์ครบและไม่ซ้ำ
10. ส่งข้อความเมื่อปลายทางหาย ปิดเปิดแอปแล้วคิวอยู่ และส่งเมื่อ reconnect
11. สร้าง A–B–C โดย A ไม่เชื่อม C ส่งข้อความ/SOS และตรวจ ACK ย้อนกลับ
12. ส่งรูปและวิดีโอไม่เกิน 5 MiB ผ่าน B แล้วหยุด B เพื่อพิสูจน์ว่าต้องใช้เครื่องกลาง
13. เปิดอินเทอร์เน็ตหลัง offline แล้วตรวจข้อความ/SOS/สื่อขึ้น Cloud จริงและ UI ซิงก์แล้วตรงกับผล
14. ตัดเน็ตระหว่าง sync และ restart แล้ว retry โดยไม่มีข้อมูลซ้ำ
15. เปิดประวัติ ค้นหา/กรอง และดูสื่อที่บันทึกครบหลัง restart ขณะไม่มีอินเทอร์เน็ต
16. ทดสอบล็อกจอ/สลับแอป การแจ้งเตือน และปิดสวิตช์แจ้งเตือน
17. ทดสอบตัวอักษรใหญ่ TalkBack ขนาดปุ่ม ความต่างสี และสถานะที่เข้าใจได้โดยไม่ดูสีอย่างเดียว
18. สมัคร/ยืนยันอีเมล/Login แล้ว restart ออฟไลน์; แยกทดสอบติดตั้งใหม่ออฟไลน์เพื่อบันทึกข้อจำกัดจริง
