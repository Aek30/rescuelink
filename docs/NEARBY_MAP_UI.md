# แผนที่รอบตัว

- หน้าใกล้ฉันแสดงแผนภาพพิกัดเหนือรายการอุปกรณ์เดิม
- กดตำแหน่งของฉันเพื่ออ่าน GPS; ไม่เผยแพร่ตำแหน่งหรือเปิด SOS อัตโนมัติ
- ใช้พิกัดจาก SOS ใน presence ที่ได้รับสำหรับหมุดเพื่อน ไม่คาดเดาพิกัดจากการค้นพบอุปกรณ์
- สีเขียวคือพิกัดเรา แดงคือ SOS น้ำเงินคือ Rescue ที่มีพิกัด เทาคือสถานะเก่า/ปิดแล้ว
- แตะหมุดหรือชื่อใต้แผนภาพเพื่อเปิดรายละเอียด เหตุที่หมุดซ้อนกันยังเลือกได้จากรายการชื่อ
- แสดงเวลาบันทึกของแต่ละพิกัด; ไม่ใช่ live tracking
- แผนภาพออฟไลน์แบบ north-up ใช้การฉายพิกัดเฉพาะบริเวณโดยประมาณ ปรับขนาดให้เห็นทุกหมุด ไม่มีถนนหรือการนำทาง ไม่ควรใช้วัดระยะไกลอย่างแม่นยำ
- หากยังไม่อ่าน GPS ใช้หมุดแรกเป็นจุดอ้างอิงและระบุว่าไม่ใช่ตำแหน่งผู้ใช้
- ทดสอบ widget: ไม่มีการขอ GPS ก่อนกด, ไม่มีหมุดตัวเองปลอม, อ่าน GPS แล้วแสดงพิกัด โดยไม่เปิด SOS
- flutter analyze ผ่าน และ build APK debug สำเร็จ; ยังต้องทดสอบ GPS/พิกัดเพื่อนบนมือถือจริง
