# แผนที่ออฟไลน์ มทร.ธัญบุรี คลองหก

## วิธีใช้

1. เปิดแท็บ **ใกล้ฉัน** เพื่อดูถนน อาคาร และแหล่งน้ำจากไฟล์ที่ติดมากับแอป
2. เลื่อน/กางนิ้ว หรือใช้ปุ่ม +/− เพื่อซูม ปุ่มดูทั้งพื้นที่กลับสู่ขอบเขตทั้งหมด
3. กด **ตำแหน่งของฉัน** เพื่ออ่าน GPS; หมุดเขียวแสดงพิกัดที่อ่านล่าสุด
4. ส่ง SOS พร้อมพิกัดจากอีกเครื่อง หมุดสีแดงปรากฏเมื่อได้รับสถานะ
5. เปิดโหมดกู้ภัยที่แท็บฉัน แล้วกลับมาใกล้ฉัน กด **อ่าน GPS และแชร์พิกัดกู้ภัย**
   อีกเครื่องจะเห็นหมุดสีน้ำเงิน ไม่จำเป็นต้องสร้าง SOS เพื่อแชร์พิกัดกู้ภัย
6. แตะหมุดคนอื่นเพื่อเปิดรายละเอียดและกด **ติดต่อผ่านแชต**
7. กด **หยุดแชร์พิกัดกู้ภัย** หรือปิดโหมดกู้ภัยเพื่อหยุดประกาศพิกัด

## ขอบเขตและพฤติกรรม

- ข้อมูลถนนจริงจาก OpenStreetMap ครอบคลุมคลองหกบริเวณมหาวิทยาลัยประมาณ 2 × 2 กม.
- ไม่มีการดาวน์โหลดแผนที่ระหว่างใช้งาน ไฟล์ JSON ประมาณ 163 KB; ไม่เพิ่ม package
- ไม่มีพิกัดจำลอง: ถ้าไม่มี GPS/พิกัดที่ได้รับ จะยังดูแผนที่ได้แต่ไม่มีหมุดผู้ใช้
- พิกัดนอกขอบเขตไม่ถูกบีบหรือย้ายเข้ามาในแผนที่ มีข้อความแจ้งและดูรายละเอียดจากรายการได้
- หมุดเทาเมื่อสถานะเก่าหรือปิดแล้ว; เวลาพิกัดแสดงแยกจากความสดของสถานะ
- พิกัดกู้ภัยเป็นการแชร์เมื่อผู้ใช้กด ไม่ติดตามต่อเนื่อง ไม่กู้การแชร์อัตโนมัติหลังเปิดแอปใหม่
- การถอนพิกัดจะถึงเครื่องอื่นเมื่อแลกเปลี่ยนสถานะใหม่ เครื่องที่ขาดการเชื่อมต่ออาจยังเก็บพิกัดเก่า
- โปรโตคอลรองรับเครื่องเก่าที่ไม่ส่ง rescueLocation และส่งต่อพิกัดกู้ภัยผ่าน directory Relay
- แผนที่ในหน้าดูพิกัด/SOS ใช้ชุดข้อมูลเดียวกัน การเปิดแอปแผนที่ภายนอกยังเป็นอีกบริการหนึ่ง
- ไม่มีการคำนวณเส้นทางตามถนน และไม่ยืนยันว่าถนนเปิดหรือปลอดภัย

## ทดสอบบนมือถือจริงก่อนสาธิต

ติดตั้ง build ใหม่ทั้งสอง/สามเครื่อง ปิด mobile data และไม่เชื่อม Wi-Fi hotspot
แต่เปิด Bluetooth/Wi-Fi radio และ GPS ตามที่ Nearby ต้องใช้ จากนั้น:

1. เปิดแอปใหม่โดยไม่มีอินเทอร์เน็ต ตรวจว่าถนนแสดงได้ทันที
2. อ่าน GPS ในบริเวณมหาวิทยาลัย ตรวจตำแหน่งเทียบสถานที่จริง
3. ส่ง SOS และแชร์พิกัดกู้ภัย ตรวจสี หมุด เวลา และการแตะเข้าแชต
4. ปิดกู้ภัย/หยุดแชร์ แล้วตรวจว่าอีกเครื่องได้รับการถอนหมุด
5. ทดสอบ A–B–C โดยไม่มีลิงก์ A–C ตรวจว่าพิกัดกู้ภัยยังส่งผ่าน B ได้
6. ทดสอบ GPS ไม่พร้อม พิกัดนอกพื้นที่ หน้าจอแคบ และธีมมืด

Automated tests ใช้ fake transport ไม่แทนผลทดสอบ Bluetooth/GPS บนโทรศัพท์จริง
