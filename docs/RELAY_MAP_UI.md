# Relay badge และแผนภาพพิกัดออฟไลน์

## Relay

- ข้อความธรรมดาในแชตแสดง badge; แตะดูเส้นทางและชื่อเครื่องที่รู้จักได้
- A → B → C คือ 2 hops และผ่านตัวกลาง 1 เครื่อง
- ใช้ relayPath ที่ตรวจรับในโปรโตคอลเดิม บันทึกเส้นทางแรกที่ปลายทางได้รับใน SQLite settings ไม่เปลี่ยนรูปแบบ packet หรือสถานะ ACK
- เก็บเส้นทางไว้หลัง restart; duplicate ไม่เขียนทับเส้นทางแรก
- ข้อมูลเส้นทางมาจาก packet ไม่ใช่ข้อมูลตำแหน่ง GPS หรือการรับรองตัวตนของแต่ละเครื่อง
- ฝั่งผู้ส่ง/ข้อความเก่าที่ไม่มีข้อมูลแสดง “ยังไม่ทราบเส้นทาง” เพราะยังไม่มี end-to-end route feedback
- ไม่แสดง hop ให้ SOS เพราะ relay ที่มีอยู่รองรับข้อความธรรมดาเท่านั้น

## พิกัดออฟไลน์

- LocationButton ใช้การ์ดแผนภาพกริดและหมุดร่วมกัน จึงปรากฏในหน้า SOS/รายละเอียดเหตุ/แชต SOS ที่มีพิกัด
- วาดด้วย Flutter CustomPainter ไม่เรียกเครือข่าย ไม่ใช้ tile หรือ API แผนที่
- แสดงค่าพิกัด ความแม่นยำ และเวลาบันทึกเดิม; หมุดอยู่กึ่งกลางพิกัดที่ได้รับ ไม่ใช่ตำแหน่งผู้ดู
- กริดและวงกลมเป็นภาพประกอบ ไม่มีมาตราส่วน ไม่มีข้อมูลถนน/เส้นทาง และไม่ใช้แทนการนำทาง
- ยังคัดลอกพิกัดและเปิดแอปแผนที่ภายนอกได้ แอปแผนที่ภายนอกต้องมีข้อมูลของตัวเองสำหรับใช้ offline
