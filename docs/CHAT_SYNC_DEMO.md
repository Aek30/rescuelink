# ตรวจการซิงค์กับ Supabase จริง

## ผลตรวจล่าสุด

ชุดทดสอบ Cloud จำลองผ่าน 15 เคส แต่การทดสอบ Supabase จริงหยุดที่ล็อกอิน: อีเมลหรือรหัสผ่านใน `config/test-account.local.json` ใช้ไม่ได้ จึงยังสรุปไม่ได้ว่าการอัปโหลดจริงผ่านหรือไม่ ไม่ได้ยืนยันว่าบัญชีที่ล็อกอินอยู่ในแอปมีปัญหาเดียวกัน

## ทดสอบอัตโนมัติกับฐานข้อมูลจริง

ใช้บัญชีทดสอบที่สมัครและยืนยันอีเมลแล้วใน Supabase โปรเจกต์เดียวกับ `config/supabase.local.json` หากจำรหัสผ่านไม่ได้ ให้ตั้งรหัสผ่านใหม่ผ่านหน้าลืมรหัสผ่านของแอปก่อน

รันจากโฟลเดอร์โปรเจกต์:

```powershell
powershell -ExecutionPolicy Bypass -File .\tool\verify_chat_cloud.ps1
```

กรอกอีเมลและรหัสผ่านในเทอร์มินัล รหัสผ่านซ่อนระหว่างพิมพ์ สคริปต์จะอัปเดตไฟล์บัญชีทดสอบในเครื่อง (มีรหัสผ่านเป็นข้อความในไฟล์ จึงห้ามแชร์หรือ commit) แล้วเรียกชุดทดสอบเดิมที่ใช้ Supabase จริง ไม่ได้สร้างบัญชีหรือเปลี่ยนรหัสผ่านให้

ผลที่ต้องได้คือ `All tests passed!` โดยเคสนี้อัปโหลดข้อความ, SOS และรูปภาพ แล้วกู้คืนลงฐานข้อมูลท้องถิ่นอีกชุดของบัญชีเดียวกัน ตรวจเนื้อหาข้อความและไฟล์จริงด้วย หลังจบทดสอบจะลบไฟล์ทดสอบและเปลี่ยนประวัติแชตทดสอบเป็น tombstone (`deleted = true`) จึงไม่ใช้แถวเหล่านี้เป็นหลักฐานข้อความที่ยังแสดงอยู่

## สาธิตจากแอปให้อาจารย์ดู

1. เปิดแอปที่เชื่อมกับ Supabase โปรเจกต์เดียวกับ Dashboard และเข้าสู่ระบบสมาชิก เปิดอินเทอร์เน็ต
2. ในแชต ส่งข้อความใหม่ `DEMO-SYNC-20261104-001` เปลี่ยนเลขท้ายทุกครั้งที่สาธิต ถ้าทดสอบ Nearby ให้เชื่อมมือถือคู่สนทนาด้วย
3. ไปที่ข้อมูลสมาชิก → การซิงก์ → ซิงก์ตอนนี้ ตรวจว่าไม่มีข้อผิดพลาดและไม่มีข้อความค้างซิงก์
4. เปิด Supabase → SQL Editor รัน `supabase/tests/chat_demo_verify.sql` โดยใช้ข้อความค้นหาตรงกับที่ส่ง
5. แสดงผลแถวที่มีข้อความตรงกัน, `message_id`, `owner_id`, `deleted = false`, `version` และเวลาไทย ให้ตรวจว่า `owner_id` เป็นบัญชีที่ใช้สาธิต และเวลาอัปเดตตรงกับรอบที่เพิ่งส่ง
6. ถ้าต้องการพิสูจน์การกู้คืน เปิดแอปอีกเครื่องหรืออีกเบราว์เซอร์ด้วยบัญชีเดิมแล้วซิงก์ ตรวจว่าประวัติข้อความเดียวกันปรากฏ

ถ้า SQL ไม่พบแถว ให้ตรวจข้อความค้นหา, บัญชี, โปรเจกต์ และข้อผิดพลาดในหน้าซิงก์ก่อน ยังไม่ถือว่าซิงก์สำเร็จเพียงเพราะคิวว่างหรือมีเวลาอัปเดต

Cloud Sync เป็นการสำรองประวัติของบัญชี การส่งถึงคู่สนทนาผ่าน Nearby เป็นอีกขั้นตอนหนึ่ง
