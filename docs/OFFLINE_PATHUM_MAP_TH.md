# แผนที่ออฟไลน์จังหวัดปทุมธานี

## การใช้งาน

- ข้อมูลแผนที่ติดมากับ APK ไม่ต้องดาวน์โหลดหรือเปิดออนไลน์ก่อน
- ครอบคลุมเขตจังหวัดปทุมธานีตาม OSM relation 1908797 รวมทั้ง 7 อำเภอ
- เลื่อน/ซูมเพื่อดูรายละเอียด กดค้างปุ่ม − เพื่อดูทั้งจังหวัด
- เมื่อมีพิกัด แผนที่จะเริ่มซูมบริเวณพิกัดนั้น หมุด SOS/กู้ภัย การแตะไปแชต และการปักหมุดเองยังใช้หน้าจอเดิม
- พิกัดนอกจังหวัดไม่ถูกย้ายเข้ามาในแผนที่ และไม่แสดงถนนสมมติ
- ไม่มีการนำทางตามถนน ข้อมูลไม่ยืนยันการปิดถนน น้ำท่วม หรือความปลอดภัยของเส้นทาง

## การลดภาระเครื่อง

รองรับการนำไปทดสอบบน Galaxy S20, Galaxy S25 และ Huawei P30 โดย:

1. โหลดเฉพาะดัชนีจังหวัดเมื่อเปิดแผนที่ ไม่โหลด geometry ทั้งจังหวัด
2. ใช้ความละเอียด 4 ระดับ: ภาพรวม / ถนนระดับพื้นที่ / ถนนย่อย / รายละเอียดอาคาร
3. แบ่งแต่ละระดับเป็นกริด 1×1, 4×4, 16×16 และ 64×64 และอ่านเฉพาะช่องที่มองเห็น
4. หากหน้าจอสูงทำให้ต้องโหลดมากกว่า 16 ช่อง จะลดระดับรายละเอียดชั่วคราวเพื่อให้ครบพื้นที่มองเห็น
5. แคช LRU ใช้ร่วมกันระหว่างหน้าจอ สูงสุด 24 ช่อง, 180,000 จุด geometry และงบขนาดข้อความที่ถอดรหัส 6 MiB
   ตัวเลขนี้เป็นเพดานข้อมูลแคช ไม่ใช่การรับรองว่า RAM ทั้งแอปใช้ไม่เกิน 6 MiB
6. อ่าน/ถอดรหัสพร้อมกันไม่เกิน 2 ช่อง ถอด JSON ผ่าน background isolate และสร้าง Path ครั้งเดียวต่อการโหลด
7. รอการเลื่อนประมาณ 80 ms ก่อนเปลี่ยนชุดโหลด ทิ้งผลที่ไม่มีหน้าจอต้องการแล้ว และหยุดคิวของหน้าที่ถูกซ่อน
8. วาดเฉพาะเส้นที่ตัดกับ viewport จำกัดข้อความบนแผนที่ 14 ป้ายต่อเฟรม และคงขนาดหมุด/ป้ายตามหน้าจอ

การแก้ไขนี้ไม่เปลี่ยนโปรโตคอลหรือการเชื่อมต่อ Nearby และไม่ได้เพิ่ม GPS tracking ต่อเนื่อง
ความลื่นและการใช้แบตเตอรี่บนมือถือทั้งสามรุ่นต้องวัดบนเครื่องจริง ไม่อ้างผลทดสอบจำลองเป็นผล benchmark ของโทรศัพท์

## ข้อมูลและการสร้างซ้ำ

- แหล่งข้อมูล: https://download.geofabrik.de/asia/thailand-latest.osm.pbf
- ขอบเขต: https://www.openstreetmap.org/relation/1908797
- ข้อมูลถนน อาคาร แหล่งน้ำ พื้นที่และสถานที่: © OpenStreetMap contributors, ODbL 1.0
- สคริปต์: `tool/prepare_pathum_map.py` ใช้ Python + osmium + shapely
- เก็บไฟล์ประเทศต้นทางไว้ใน `tmp/pathum-map/` เพื่อประมวลผลเท่านั้น ไม่บรรจุทั้งประเทศไทยใน APK
- ผลลัพธ์ที่บรรจุจริง: `assets/maps/pathum/index.json` และไฟล์ช่องแผนที่ในโฟลเดอร์เดียวกัน
- sourceCounts, tileBytes และ osmTimestamp ใน index เป็นค่าจากชุดข้อมูลจริง

## ทดสอบมือถือก่อนสาธิต

ติดตั้ง APK รุ่นเดียวกันทั้ง 3 เครื่อง เปิดแอปโดยไม่มีอินเทอร์เน็ต แล้วตรวจ:

1. ดูภาพรวมทั้งจังหวัดและซูมมหาวิทยาลัย/รังสิต/เมืองปทุมธานี/ลาดหลุมแก้ว/หนองเสือ
2. เลื่อนเร็วหลายครั้งและสลับหน้าจอ ตรวจว่าไม่มีช่องว่างค้างหลังหยุดเลื่อน
3. หมุดตำแหน่งจริง แตะ SOS ไปแชต ปักหมุดเอง และข้อความกรณีอยู่นอกจังหวัด
4. ส่งข้อความ/รูป/วิดีโอระหว่างเปิดแผนที่ แล้วดูว่า Nearby ยังทำงานตามเดิม
5. ตรวจความลื่นและความร้อนบน Huawei P30 เป็นพิเศษ พร้อมทดสอบโหมดประหยัดพลังงานตามการใช้งานจริง

## การแก้ชื่อสถานที่และผลตรวจล่าสุด

- วางตัวอักษรในพิกัดหน้าจอด้วยขนาดปกติ เพื่อหลีกเลี่ยงการปัดเศษฟอนต์ขนาดเล็กก่อนขยาย
- ตรวจกรอบข้อความชนกัน เว้นบริเวณหมุด ปุ่ม ขอบจอ และเครดิต; ชื่อถนนหมุนตามแนวเส้นถนน
- อาคารแสดงเมื่อซูมเข้า; แผนที่ย่อซ่อนชื่อเพื่อความชัดเจน
- ชุดทดสอบแผนที่/แคชผ่าน 6 รายการ; ภาพตัวอย่างใช้พิกัดสาธิต ไม่ใช่ตำแหน่งเครื่องจริง
- การทดสอบทั้งแอปก่อนแก้ป้ายรอบสุดท้าย: ผ่าน 237 ข้าม 5 ไม่ผ่าน 4 ในหน้า Nearby (overflow และตัวค้นหาปุ่มหยุดไม่พบ) จึงยังไม่รับรองว่าทุกฟีเจอร์ผ่าน
- ยังไม่ได้วัด FPS/RAM หรือทดสอบเชื่อมต่อ 3 เครื่องจริงในรอบนี้
