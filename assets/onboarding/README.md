# Onboarding illustrations

Generated using the built-in image_gen tool for the three introduction pages.
These are new illustrations inspired by the supplied reference, not exact crops.
UI copy, cards, navigation and branding are rendered separately in Flutter.

Files: welcome.png, nearby.png, sos.png.

## Final prompts

### welcome.png
Use case: illustration-story. Create a portrait mobile onboarding background illustration, 1024x1536. Warm detailed anime storybook style matching a Thai RescueLink disaster relief app: golden sunset sky, mountains and small Thai town, emergency tents and community volunteers. Foreground lower half: orange uniform rescue worker seen from behind with navy backpack and plain medical cross, helping elderly woman, mother and child in a relief camp. Hopeful, human, orange/navy/cream palette. Upper third mostly open golden sky for app logo overlay. Full bleed artwork only, no device frame, no text, no logos, no buttons or UI.
